# BinWu Project Portfolio

This repository contains my university programming projects, software engineering coursework, database design assignments, business planning work, and data analytics / machine learning group assignments. The projects show my experience in Java programming, object-oriented design, database modelling, UML diagrams, UI / UX prototyping, system analysis, virtualization concepts, and applied data analytics.

## Projects

### Climate Change OOP Assignment

**Type:** Java console application  
**Tech stack:** Java 21, Maven, Object-Oriented Programming  
**Files:** `src/`, `pom.xml`, `CLIMATE_OOP_README.md`, `FILE_ANALYSIS.md`

This is a Java console-based climate change information platform. It includes public user registration and login, climate data viewing, climate news viewing, climate education content, preventive measures, disaster preparation guidance, comments, and a government admin portal for managing climate data, news, and education content.

The project demonstrates object-oriented programming concepts through separate entity classes for climate data, climate news, and climate education content. It also includes menu-driven interaction, data management with collections, input validation, and basic CRUD operations.

### Gym Database System Assignment

**Type:** Database systems group assignment  
**File:** `ASSIGNMENT GYM.docx`

This database systems assignment focuses on designing and analysing a gym management database. The work includes entity relationship modelling, physical database design, extended ER modelling, SQL deployment, and SQL report generation.

The system covers gym-related entities such as members, instructors, classes, equipment, attendance, equipment rental, personal training, packages, points tracking, merchandise, and friend relationships. It demonstrates database design thinking, relationship modelling, SQL query writing, and report-based data analysis.

### HotelCatz Website System

**Type:** Software engineering group assignment  
**File:** `ITS64604_Group Assignment_Kilo3.docx`

This software engineering project proposes and models a website system for HotelCatz, a pet hotel service platform. The project addresses problems such as difficult website navigation, limited booking convenience, outdated design, and staff difficulty in managing website content.

The assignment includes requirements analysis, use case diagrams, class diagrams, prototype model explanation, GUI storyboard, website page design, admin navigation flow, booking features, gallery management, blog management, and content editing functions. It demonstrates software modelling, UML design, requirements documentation, prototyping, and user-centred system planning.

### Systems Fundamentals - Virtualization and Hypervisor Analysis

**Type:** Systems fundamentals group assignment  
**File:** `ITS66504_202409_Assignment2_Group_28.pdf`

This assignment analyses the relationship between Moore's Law, virtualization, and hypervisor technology. It discusses server virtualization, full virtualization, paravirtualization, operating-system-level virtualization, and the role of hypervisors in solving real-world IT infrastructure problems.

The report applies virtualization concepts to several business scenarios, including legacy system support, software testing, system integration, network virtualization, centralized control, and IT hardware investment optimization. It demonstrates understanding of computing infrastructure, virtualization benefits, and technical decision-making.

### Data Analytics and Machine Learning Proposal for TNB

**Type:** Data analytics and machine learning group assignment  
**File:** `ITS69304_GROUP5_GROUPASGNMT.pdf`

This project proposes a data analytics and AI-based solution for improving the customer digital experience of Tenaga Nasional Berhad (TNB). The report identifies issues in customer feedback visibility, complaint handling, digital service experience, and operational responsiveness.

The proposal covers problem identification, solution overview, comparison with existing solutions, success KPIs, data modelling, machine learning algorithms, data processing technologies, system architecture, executive dashboard design, alert thresholds, and recommended tools. It demonstrates applied machine learning planning, data pipeline thinking, dashboard design, and business-oriented analytics.

### Looplet Business Plan

**Type:** Startup ideation and business planning group assignment  
**File:** `G12_Looplet Business Plan.pdf`

Looplet is a startup business plan for a community-driven secondhand marketplace designed to support Malaysia's B40 community. The concept focuses on affordable goods, verified sellers, boosted listings, analytics, donations, and social impact aligned with poverty reduction goals.

The business plan includes executive summary, company description, target customers, market analysis, product and service offering, marketing strategy, customer needs, competitive analysis, expansion opportunities, operations planning, financial considerations, and social impact positioning. It demonstrates startup ideation, business model development, customer analysis, and strategic planning.
